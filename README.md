#########################
# Previsão Sazonal #
#########################

Nesse projeto estão os scripts que geram as previsões climáticas sazonais calibradas do multimodelo NMME + BAM e também do multimodelo Copernicus + BAM, além de gerar também os modelos separados. Os scripts geram tanto as saídas referentes à verificação determinística e probabilística das previsões sazonais, bem como os scripts que geram rotineiramente as previsões sazonais em tempo-real.
