# Visualizador Streamlit

Execute a partir da raiz do projeto:

```bash
streamlit run streamlit/app.py
```

O app procura as figuras em `PATH_FIG` por padrao:

```text
/dados/mmclima/multimodelo/seasonal/figures
```

Na barra lateral, voce pode trocar a pasta das figuras e clicar em `Atualizar lista`.
